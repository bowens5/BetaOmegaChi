# Club Website – React & Firebase

## Overview
A full-stack web application built to support a university social club by centralizing events, announcements, and member-facing information. The site was designed to be easy to maintain by non-technical users while remaining scalable and secure.

## Features
- Responsive single-page application (SPA)
- Event listings with dates and descriptions
- Firebase-backed data storage
- Modular React components for maintainability
- Clean, accessible UI designed for everyday student use

## Technologies Used
- **Frontend:** React, JavaScript, HTML, CSS
- **Backend / Services:** Firebase, Firestore
- **Tooling:** Git, GitHub

## How It Works
The application is built as a React single-page application using reusable components for layout, navigation, and content sections. Event data is stored in Firebase Firestore and fetched dynamically by the frontend. The structure allows club officers to update content without modifying core application logic.
